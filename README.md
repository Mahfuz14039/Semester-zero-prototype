# 🎓 Semester Zero

**First semester. No rules. Plenty of consequences.** 😏

A 3D campus adventure that runs right in your browser. You're the new freshman at Ashgrove College 🏫 — register, meet your classmates, survive class, and stand up to the campus bully.

## ✨ Features
- 📚 Story missions: registration, orientation, Math quiz, finals
- 🥊 Combat: combos, uppercut, dodge, block
- 🏅 Medals to unlock
- 💾 Save & load
- 📱 Touch controls for phones

## 🎮 Play
👉 **[Play Now](https://YOUR-USERNAME.github.io/YOUR-REPO/)**

Or download the file and open it in Chrome, Edge, or Firefox. No install needed ✅

## 🕹️ Basic Controls
`WASD` move · `Shift` sprint · `Space` jump · `E` talk · `F` punch · `Q` block · `K` all controls

Made with ❤️ using Three.js
